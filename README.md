# Focus — Pomodoro timer for iOS 26

A minimal Pomodoro timer and task list for iPhone with a terminal look (iOS 26+). This repository holds the **downloads**: every build of the app, its release notes, and the SideStore source. The source code is private.

- Focus / break timer up to 8 hours each: hour and minute wheels, quick chips and your own presets, with sounds and Core Haptics
- Five terminal styles (Mono, the default, matches the website; plus Cozy, PowerShell, CMD, Ubuntu), each with its own boot screen, panic screen and buttons, and 20 mono fonts
- Dynamic Island and lock-screen Live Activity with pause and switch-mode buttons, plus Home Screen widgets
- Panic screen when you try to quit a focus block early, and a history of finished and given-up blocks
- Focus guard: block distracting apps and silence notifications through Shortcuts
- Task list: add, check off, reorder, and tap a task to make it the one you're focusing on
- Optional Spotify now-playing controls and Google Calendar logging of finished focus blocks
- Tasks and sessions sync (optional account with a 6-digit email code); works fully offline
- In-app update notices, plus a SideStore source for one-tap updates
- English and Vietnamese (Tiếng Việt): pick it in the setup guide or Settings → appearance
